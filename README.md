# UltimateSponge

Paper 26.2用の、1チャンク全体の水を吸収する最強スポンジプラグインです。

## 仕様

- 最強スポンジを設置すると、そのスポンジがある1チャンクを全高度走査します。
- 水源、水流、泡の柱、昆布、海草、水没ブロックの水を除去します。
- 大きな処理は複数tickへ分割し、サーバーの瞬間的な停止を防ぎます。
- 水を吸収したスポンジは「濡れた最強スポンジ」になります。
- 濡れた最強スポンジのかまど乾燥時間は、通常の20倍です。
- 乾燥後は再び最強スポンジとして使用できます。
- 設置済みの専用スポンジ情報はチャンクへ保存され、再起動後も維持されます。

## コマンド

- `/usponge give dry [個数]` - 自分に最強スポンジを渡します。
- `/usponge give wet [個数]` - 自分に濡れた最強スポンジを渡します。
- `/usponge give <プレイヤー> <dry|wet> [個数]`
- `/usponge reload`

配布と再読み込みは初期設定でOP専用です。設置は全プレイヤーが可能です。

## 設定

`plugins/UltimateSponge/config.yml` で1tickあたりの走査量、水没ブロックの処理、
乾燥時間倍率を変更できます。通常の乾燥時間が200tickの場合、20倍では
4000tick（3分20秒）です。


## ビルド

JDK 25とMaven 3.9以降を用意し、リポジトリ直下で `mvn clean verify` を実行します。
生成物: `target/UltimateSponge-1.0.0.jar`。Paper 26.2の `plugins` フォルダーへ配置して再起動してください。
